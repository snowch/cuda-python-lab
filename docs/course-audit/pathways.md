# Visualisation opportunities across the proposed curriculum

Use [the current lesson matrix](lessons.md) for the 17 milestones, appendix and compiler notebook. The table below maps the remaining topics in the issue's A–L proposal to the question a learner must answer. A shared row means the named lessons revisit the same model with one additional control. S/M/L indicate relative implementation and verification cost, including authoring. P1 is core learning value, P2 is specialist depth. Start with the models that change the learner's next prediction.

## Delivery contract

Use typed fixture values, shape, dtype and launch geometry from the selected case. The reusable components are a selectable indexed array, lane/address table, step controller, resource budget table, timeline and evidence comparison. Each model declares its domain, equations and version. Mount it immediately beside its prediction and the relevant live expression. Use a source hash for each captured run; recover after reload and label earlier evidence when input, program or case changes. Offer explicit reversible patches with a diff. Free-form changes outside a model's contract return it to a clearly identified example or disable it until the learner chooses a supported variant.

A sector grouping is a calculation. A source-level shared-memory schedule illustrates a permitted ordering. Neither is a simulator trace. For actual simulator evidence retain stdout, PTX and program identity. For a hardware point require the device, compute capability, driver/tool versions, shape, dtype, warmup, repetitions, timing boundary and correctness check. Keep a measured artifact downloadable.

Use one adjustable parameter initially, optional prediction and explicit reveal. Provide keyboard-selectable cells, an equivalent textual trace and focus-preserving Previous/Next/Restart. Temporal models start paused. Use shape or text as well as color. At 320 px wrap blocks and scroll labelled dense tables locally. Apply both themes, reduced motion and offline asset budgets. Keep a scalar reference for each model and test boundary inputs in this matrix. Verify against independent arithmetic before linking any result to editor state.

Beyond the supplied designs, prototype the coverage counterexample and the evidence comparison before advanced animations. One missing write in an otherwise zero output, an accidentally carried kernel with a correct answer, and a result from an older source revision are three different failure modes. Seeing exactly which code and fixture produced a value is a prerequisite for diagnosing all three.
