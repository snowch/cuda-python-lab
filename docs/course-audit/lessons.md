## Text and evidence placement

Keep “Kernel edits carry across cases. The host code has a draft for each case.” Move it beside a concrete action when a task asks for the starter. For softmax step 3, use “Select Two rows · 37 columns. Open Editor tools → Restore starter. Run. Find the two columns written by Lane 0.” Keep undo available. For precision, label the two comparisons “Matches starter arithmetic” and “Error relative to exact sum”. A wrong starter match can accompany a better approximation.

Before “A sector is an aligned group of 32 bytes”, let the learner point to the four bytes belonging to one FP32 element. Replace the first fixed table of addresses with the same table generated from the chosen lane group. Keep it readable without drawing arrows. Before “At distance four”, show which two scratch slots thread 1 can read and when they become initialized. Ask for a prediction before revealing the addition. Use glossary links for optional depth and put required definitions inline.

## Editorial decisions in teaching order

The excerpts below identify where to revise or retain the opening, prediction and interpretation. The numbered actions and answers are reviewed in the matrix above. Apply corrections in the lesson, transcript and export whenever they share an assumption.

| Lesson | Passage and editorial decision |
|---|---|
| First value | “It compiles a kernel into machine code for an NVIDIA GPU” compresses the native compiler and driver into one actor before the learner knows which backend Run uses. Introduce the first store, then name the browser compiler and simulator beside Run. Keep “The original CPU array still holds zero” next to the two prints. |
| Vector add | “In main(), the launch starts enough whole blocks” describes the prepared launch well. Add “main uses ceiling division when choosing that number” and apply it to n=33. Scope “every thread with i ≥ 33” to that case; the exact-fit case has n=32. |
| Grid stride | “The loop stops before n ... so each thread covers a different set” joins two distinct claims. The stop condition bounds each visit; distinct starting residues modulo the total thread count prevent overlap. Ask for the *first* common index of the faulty trails; 7 is not their only overlap. |
| Transfers | Retain separate sentences for output allocation and host copies. “Each active thread reads” is a source operation count. Label the byte question “logical bytes requested by these copies” so a shared-DRAM reader can answer without guessing the interconnect. |
| Coalescing | Keep “assume each array starts on a sector boundary” visible for each address calculation. Introduce x-fastest lane numbering immediately above the rectangular mapping rather than before the first visible matrix. For values_host, specify “the first eight elements in row 0” to avoid treating the first eight rows of a 2D array as eight scalar entries. |
| Divergence | Keep the word “can” in “A GPU can run a path with only the lanes that chose it active.” The outputs reveal sign classes. Refer to a PTX conditional branch or predication only after inspecting the generated program. |
| Reduction | The text already states the power-of-two and scratch-capacity restrictions. Retain them next to any width control. “What must be ready” is a better prediction than just asking for the sum; require identification of the producer and consuming lane. |
| Histogram | “Each increment is counted even when several threads choose the same counter” applies to atomic increments with this initialized counter and range. Retain the fresh-zero setup. Pair “can vary” with two worked schedules since one device can repeat the same result. |
| Scan | “A kept item's position is its running total minus one” is correct for these flags. Ask what would happen if that expression were used for a discarded item. The weighted variant counts contributions and needs a separate application question. |
| Tiled transpose | “Padding ... changes where the next row starts” is precise. Preserve “can delay” for conflicts and give bank and distinct-word counts. The one-thread prediction is about producer ownership, which can be checked before making a whole-warp claim. |
| Matmul | The opening already defines the dot product. Replace the jump to a full 4×4 tile with one selectable output; preserve the second barrier explanation about reusing the tile. Ask which output row and column consume a chosen staged value. |
| Softmax | “Every shifted score [is] zero or negative” assumes finite input with a finite maximum. State the domain, attach the actual selected row to the prediction and explain why exp(0)=1 before the first stability edit. |
| Gather | “If the eight indices are ...” describes the spaced fixture while the default program starts consecutive. Name the case explicitly. Distinguish addressing the index list, loading an index and addressing the value. Retain the explicit statement that direct indexing changes the result. |
| Stencil | “Which input from Block 0” can imply that one block owns an input in global memory. Use “which global input index just left of Block 1's output range”. The answer is input[7], staged in Block 1's own tile[0]. |
| Precision | “The first case starts with a values of ...” uses an array name that reads as an article. Say “The first two elements of a are ...”. Keep the distinction between the original FP32 grouping and the exact sum. |
| Sync debug | Replace “What happens to the barrier if that thread returns first?” with “Which write and which barrier participation are missing? Which surviving thread consumes that slot?” Gives a determinate answer without asking for a predicted native hang. |
| Fusion | “These two cases each launch one kernel” is accurate for the compared pair, but the selector has three cases. Name “8 values · store temporary” and “8 values · keep local”; label the 13-value case as an edge check. Show whether the temporary is still allocated. |

**Shared labels.** Keep “Run”, “Stop”, “Restore starter”, “Undo restore” and “Inspect compiled PTX”. For return visits, surface the case and source associated with the previous run next to its output. “Mark lesson complete” records a reading decision; the future practice score needs its own label. Keep “Free memory” beside the measured WASM allocation and a statement that edits survive it. On the appendix, label profiling commands by tool, expected evidence and hardware requirement. On the compiler download, retain the definition of cold and warm scope and identify which cells intentionally reuse the same specialization.
