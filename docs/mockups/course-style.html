Write your first GPU value

Launch one thread, write one value, and read it back in main().

Which value does the CPU print?

hello is a kernel: a function that runs on the GPU. A GPU thread runs the kernel's body once. Here, the single thread stores a value at output[0] in GPU memory.

A block is a group of GPU threads. The two 1s in the launch below request one block containing one thread.

Where does the value go?

        
An SM (streaming multiprocessor) is a part of the GPU chip that runs threads. The kernel writes into GPU memory. main() copies that value into the CPU variable value before printing it.

        
      

      

        
Change the value and run again

        
In hello, change output[0] = 42.0f to output[0] = 7.0f. Predict the printed number and click Compile and run again. Can the launch still use one thread?

Read the transcript
The CPU requests one thread. An SM runs that thread, which stores a value in GPU memory. The CPU copies the value into its own memory before printing. Changing the stored number changes the output; it does not require more threads.
